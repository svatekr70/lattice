bez balastu.

Lattice je framework-agnostická datová mřížka (grid) ve vanilla JS. Žádné runtime závislosti, žádný build krok — jeden ESM soubor, který si počítá, a aplikace si persistuje.

vanilla JS · ESM 0 závislostí bez buildu ~211 kB z CDN MIT
▶ Živé demo 📘 Uživatelská příručka API dokumentace 
<!-- jeden request z CDN, žádný build -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/svatekr70/lattice@main/dist/lattice.css">
<div id="grid"></div>
<script type="module">
  import { Lattice } from 'https://cdn.jsdelivr.net/gh/svatekr70/lattice@main/dist/lattice.min.js';
  new Lattice('#grid', { columns, data });
</script>

Pro produkci připni verzi (@v1.6.2) místo @main. K dispozici i přes npm i lattice.

Co umí

Kompletní tabulková logika v jednom souboru — od filtrů přes stromy až po export.

▦

Bohaté datové typy

14 vestavěných formátovačů: text, čísla, měny, data, boolean, progress, hvězdičky, sparkline, odkazy, obrázky s lightboxem, ikony, barvy, HTML. Vlastní typy přes registerType().

⌕

Filtry pro každý sloupec

Text, číselné rozsahy, kalendářní rozsahy, select/multiselect, boolean. Umístění v záhlaví, v panelu, nebo univerzální „Pole/Typ/Hodnota". Navíc rozšířený filtr se stromem AND/OR pravidel.

⋔

Stromová zobrazení

Zanořená data, plochá s parentId, i nested-set (lft/rgt). Filtry i hledání fungují i ve stromu — zachovají cestu k nálezu a rozbalí větev.

✎

Inline editace & validace

Editace přímo v buňce podle typu sloupce, s validací a historií změn (undo/redo). Knihovna počítá, událostí on… si aplikace řídí persistenci.

∑

Seskupení & souhrny

Skupiny řádků, souhrnné řádky (sum, avg, count…), stránkování i virtuální scrollování pro velké datasety.

⇄

Přesun & výběr

Přetahování a řazení řádků i sloupců, ukotvené sloupce, změna šířky, výběr rozsahu buněk a kopírování do schránky.

⭳

Export & tisk

Export do CSV a JSON, tiskový výstup, HTML tabulka. Import z CSV/JSON a XML feedů.

🎨

Motivy & formát

Světlý/tmavý motiv, CSS proměnné --lattice-*, hustota řádků, otočení hlaviček, formáty čísel a dat — vše přes dialog „Nastavení tabulky".

🌐

Lokalizace

Vestavěná čeština a angličtina, snadné přidání dalších jazyků. Vlastní překlady přes i18n.

💾

Presety & persistence

Uložení a přepínání pojmenovaných nastavení, deterministický init, stav do URL pro sdílitelné odkazy. Jeden zdroj pravdy.
